## The haau3 platform API

One key, one FHIR base, at [api.haau3.com](https://docs.haau3.com):

- **Scheduling:** open appointment slots from many SMART Scheduling Links publishers, in one search.
- **Plan Benefits:** Medicare Advantage and ACA Marketplace plans as FHIR `InsurancePlan`, searchable by state or county.
- **MedList:** one reconciled medication list from one patient's FHIR medication records.
- **Terminology, Provider directory and Questionnaires:** RxNorm and LOINC lookups, practitioners and organizations from CMS's National Provider Directory, and standard FHIR Questionnaires such as the PHQ-9.

The platform API is in preview. It may change as we build, usually to add features or improve performance.
